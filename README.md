# Calculadora de IMC (Índice de Masa Corporal)

Una aplicación sencilla para calcular el Índice de Masa Corporal (IMC) a partir del peso y la altura ingresados por el usuario, categorizando el resultado según las escalas estándar de salud.

---

## 🚀 Características

- **Cálculo instantáneo:** Obtén tu IMC de forma rápida.
- **Categorización clara:** Clasifica el resultado según los rangos de la OMS (Bajo peso, Peso normal, Sobrepeso, Obesidad, etc.).
- **Interfaz intuitiva:** Diseñada para ser fácil de usar en cualquier dispositivo.

---

## 📐 Fórmula utilizada

El cálculo del Índice de Masa Corporal se realiza mediante la siguiente relación:

$$\text{IMC} = \frac{\text{Peso (kg)}}{\text{Altura (m)}^2}$$
